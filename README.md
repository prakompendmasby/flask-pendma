# Pendma Kota Surabaya (Python-Flask)

# Step by step
1. python -m venv (change "venv" with env folder name, default venv)
2. Install python vscode
3. Ctrl + Shift + P select intreperter
4. Use git bash terminal
5. source venv/Scripts/activate
6. pip install --upgrade pip
7. pip install -r requirements.txt
8. python main.py

# Key note
- pip install -r requirements.txt --force-reinstall
